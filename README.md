# ExpenseFlow — Personal Finance Dashboard

A clean, classic personal-finance dashboard built with **HTML5, modern CSS and vanilla JavaScript**. It combines a polished responsive interface with practical browser-based data persistence.

## ✨ Features

- Elegant responsive dashboard UI
- Income / expense transaction management
- Automatic balance and monthly spending totals
- Category spending visualization using the Canvas API
- Search and filter transactions
- Delete transactions
- Dark mode with saved preference
- LocalStorage persistence — no backend required
- Accessible labels and responsive mobile layout
- Zero framework dependency; fast static deployment

## 🧠 Technical highlights

- Semantic HTML5
- CSS custom properties and responsive CSS Grid/Flexbox
- JavaScript ES6+
- Web Storage API (LocalStorage)
- Canvas API for the spending chart
- `crypto.randomUUID()` with fallback for transaction IDs
- Defensive HTML escaping for user-entered transaction text

## ▶️ Run locally

Open `index.html` in a modern browser, or use VS Code Live Server.

## 🌐 Deploy

The project is a static site and can be deployed on GitHub Pages, Netlify or Vercel.
